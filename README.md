# Max Combo（Android 转珠路线工具）

给《Puzzle & Dragons》/《龙族拼图》用的 Android 版「看盘 → 给路线」工具。
和 iOS 版做的是同一件事：读屏幕、算一条多 combo 的拖动路线，用悬浮窗浮在游戏上，你自己照着划。

**Android 比 iOS 省事得多：** 单进程、不需要广播扩展、不需要 App Group、不需要 Mac。
GitHub Actions 直接云编译出 **debug APK，手机允许「未知来源」就能装**，不用签名工具、不用 7 天重签。

> 这份代码没有在真机上编译验证过（开发机是 Windows，没有 Android SDK）。第一次云编译大概率只会碰到 1~3 个小错（import、API 签名），把 Actions 日志贴出来就能改。

## 它怎么工作

```
┌────────────────────── Android 手机 ──────────────────────┐
│  P&D 游戏（你照着白线划）                                 │
│      ↑                                                   │
│  悬浮窗（珠子 + 白色路线 + combo 数，可拖动）             │
│      ↑ Canvas 直接画                                     │
│  求解器：模拟退火搜整条路径（约 6~7 combo，<0.2s）        │
│      ↑                                                   │
│  识别：按校准框切 6×5 格心，5×5 像素均值，最近邻比 6 色   │
│      ↑ MediaProjection 每 0.9s 抓 1 帧（降采样到 ≤900px） │
└───────────────────────────────────────────────────────────┘
```

- `app/.../core/PDBoard.kt` —— 盘面模型。一次拖动的净效果：路径上的珠整体后移一格，起手那颗落到终点；消珠按行列 3 连、连锁下落重算，combo = 清除的组数（含连锁）。天空掉落随机，故意不计。
- `app/.../core/PDSolver.kt` —— SplitMix64 确定性 RNG + 模拟退火搜路径（长度上限 24 格，约 5 秒手速）。评分 = combo×10 − 0.35×路径长度。
- `app/.../core/OrbRecognizer.kt` —— 格心取均值，绿色通道加权的最近邻分类（心珠粉 / 火珠红最容易混）。
- `app/.../capture/PadService.kt` —— 前台服务：MediaProjection 抓帧、识别、求解、维护悬浮窗，全在这一个类里。
- `app/.../overlay/RouteBoardView.kt` —— 画珠子 + 白路线 + 起点圈，主界面预览和悬浮窗共用。

## 算法是验证过的

`Tools/` 是与 Kotlin 逻辑 1:1 的 Python 参考实现（从 iOS 版原样搬来）：

```bash
cd Tools
python verify.py      # 机制 + 一致性 + 压力测试
python pad_sa.py      # 质量基准：平均 ~6.6 combo（Python，Kotlin 会更快）
```

覆盖：两格拖动=交换、路径整段后移、非路径格不变、4 连消除、重力压实、多组同时消=多 combo、求解结果可复现、路径始终相邻。

## 怎么装（云编译，不需要电脑装 SDK）

1. 把整个 `maxcombo-android/` 推到 GitHub 仓库。
2. 仓库 **Actions** 页手动跑 `build-apk`（工作流已附，用 GitHub 的 Ubuntu 机器编译）。
3. 下载产物 `app-debug.apk`，发到手机安装。
4. 首次安装后手机要允许「未知来源应用」；打开 App 先给**悬浮窗权限**，再点「开启助手」允许**屏幕录制**。

> debug APK 用的是 Android 默认调试签名，能直接装；要上架或长期用再配 release keystore。

## 用法

1. 打开 P&D，进到要转珠的那一回合。
2. 打开本 App → 「开启助手」→ 允许屏幕录制。
3. 悬浮窗浮在游戏上（按住可拖到不挡盘面的位置）。
4. 每回合盘面一变，约 1 秒后路线更新，从白圈起点照着白线划。

**校准**：识别错位时，用主界面四个滑杆（左/上/宽/高）把框对到 6×5 珠阵，松手即保存，无需精确到像素。

## 已知限制

- **识别是最大变数**。参考色在 `OrbRecognizer.REFERENCES`，换主题/机型可能要重调这 6 个值。
- 求解不预测天空掉落，实际 combo 通常比显示的多。
- 路径超过 24 格超出 5 秒手速，意义不大。
- 每回合要你在 App 里点一次开启（已开着则持续运行）；Android 不允许 App 偷看别的 App，屏幕录制必须你授权。

## 风险

这是外部辅助工具，P&D 的用户条款不欢迎这类做法，账号风险自担。它不读游戏内存、不注入、不代替你划，只做「看画面 + 画路线」。当练习器用更稳：看一条 7 combo 的路线长什么样，照着划几遍，手感就上来了。

## 与 iOS 版的差异

| | iOS 版 | 本 Android 版 |
|---|---|---|
| 取屏 | ReplayKit 广播扩展（要手动开录屏） | MediaProjection（App 内一次授权） |
| 浮窗 | 画中画 ~340×210，只能小窗 | SYSTEM_ALERT_WINDOW，可大可小可拖动 |
| 跨进程 | App Group / UDP localhost | 不需要，单进程 |
| 装机 | Mac 编译或云编译 ipa + Sideloadly 自签（7 天） | 云编译 debug APK，直接装 |
